# Cờ vua — Local Pass & Play

Bản web tĩnh của repo `covua`, giữ nguyên `ass/` và `assneo/` làm nguồn ảnh cho các repo khác.

## Chạy
Mở `index.html` qua GitHub Pages hoặc một static server. Không cần Python, tài khoản, database hay backend.

## Tính năng hiện tại
- Hai người chơi luân phiên trên cùng một thiết bị.
- Đồng hồ 1, 3, 5, 10, 15 phút.
- Đi lại, xoay bàn, đầu hàng.
- Xem nước đi và xuất PGN.
- Ảnh quân cờ tải trực tiếp từ `assneo/`.

## Giới hạn
Đây là chế độ local pass-and-play, không phải multiplayer online qua hai thiết bị. Game Review và phân tích Stockfish chưa được triển khai trong bản này.
